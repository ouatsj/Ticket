# Installation — Rakieta

## iPhone / iOS (recommandé)

1. Ouvrez Safari : https://ticket.rakietabus.com/assets/tei/ios/
2. L’accueil Rakieta s’affiche (Accueil, Départs, Finances, Analyse).
3. Touchez **Partager** → **Sur l’écran d’accueil** → Ajouter.
4. L’icône **Rakieta** apparaît comme une application.

Staging : https://essaiticket.rakietabus.com/assets/tei/ios/

Une version native App Store / TestFlight nécessite un Mac + compte développeur Apple.

## Android (smartphone)

1. Ouvrez sur le téléphone : https://ticket.rakietabus.com/assets/tei/
2. Touchez **Télécharger Rakieta** (Android).
3. Le fichier `rakieta.apk` se télécharge.
4. Autorisez l’installation depuis Chrome / fichiers si le système le demande.
5. Ouvrez l’APK et validez l’installation.
6. Lancez **Rakieta** : l’accueil s’affiche directement (pas d’écran de connexion).

### Mises à jour

Quand une nouvelle version est publiée sur le serveur, l’application détecte
automatiquement `version.json` au démarrage et propose de télécharger / installer
la mise à jour. Vous pouvez aussi vérifier depuis **Profil → Vérifier les mises à jour**.
