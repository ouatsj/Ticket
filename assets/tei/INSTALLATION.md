# Installation — Rakieta Lab

## Android (smartphone)

1. Ouvrez sur le téléphone : https://essaiticket.rakietabus.com/assets/tei/
2. Touchez **Télécharger pour Android**.
3. Le fichier `rakieta-lab.apk` se télécharge.
4. Autorisez l’installation depuis Chrome / fichiers si le système le demande.
5. Ouvrez l’APK et validez l’installation.
6. Lancez **Rakieta Lab** : l’accueil s’affiche directement (pas d’écran de connexion).

### Mises à jour

Quand une nouvelle version est publiée sur le serveur, l’application détecte
automatiquement `version.json` au démarrage et propose de télécharger / installer
la mise à jour. Vous pouvez aussi vérifier depuis **Profil → Vérifier les mises à jour**.

## iPhone / iOS

L’installation libre d’un fichier n’est pas possible comme sur Android.
La distribution passe par **TestFlight** ou l’**App Store** (compte développeur Apple).
