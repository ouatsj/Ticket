# Installation — Rakieta Lab

## Android (smartphone)

1. Ouvrez sur le téléphone : https://essaiticket.rakietabus.com/assets/tei/
2. Touchez **Télécharger pour Android**.
3. Le fichier `rakieta-lab.apk` se télécharge.
4. Autorisez l’installation depuis Chrome / fichiers si le système le demande.
5. Ouvrez l’APK et validez l’installation.
6. Lancez **Rakieta Lab** : l’accueil s’affiche directement (pas d’écran de connexion).

### Mises à jour

Quand une nouvelle version est publiée, l’app lit `version.json` au démarrage et propose
l’installation. Vérification manuelle : **Profil → Vérifier les mises à jour**.

## iPhone / iOS

Distribution via TestFlight / App Store uniquement.
